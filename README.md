# Placement Dashboard

An ASP.NET Web Forms placement dashboard using native Web Forms data controls (`GridView`, `DropDownList`, and `Repeater`) and a Crystal Reports viewer/export page.

## Requirements

- Visual Studio with the **ASP.NET and web development** workload
- .NET Framework 4.8 Developer Pack
- SAP Crystal Reports, developer edition for Visual Studio, and its matching runtime (same process architecture as IIS Express)

Open `PlacementDashboard.csproj` in Visual Studio and run with IIS Express. The dashboard uses an in-memory sample placement dataset so it can be explored without configuring a database. Replace `PlacementRepository.GetPlacements()` with your approved data source before production use.

## Crystal Reports setup

Crystal Reports definitions (`.rpt`) must be designed or saved with the SAP Crystal Reports designer; the proprietary report file is not generated by this project. Create `Reports\PlacementSummary.rpt` with a data source matching the `Placements` table returned by `PlacementRepository.GetReportData()`, then add the `.rpt` file to the project. Its field names and types are:

| Field | Type |
| --- | --- |
| `StudentId`, `StudentName`, `Program`, `Company`, `Role`, `Status` | String |
| `PackageLpa` | Decimal |
| `AppliedOn`, `OfferDate` | DateTime (`OfferDate` can be null) |

The report page loads the path configured by `CrystalReportPath` in `Web.config`, binds the sample data, and exposes the Crystal Reports viewer's print/export actions. The report page shows a setup message if the file is absent. If the Crystal assemblies are not found by Visual Studio, configure the Crystal Reports assembly references for your installed SAP Crystal Reports developer edition.

The sample records and season dates are illustrative only. Connect the repository to your institution's data source and configure authentication, authorization, and data-protection policies before deployment.
